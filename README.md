# help.vrcru.org

Весь проект на 99% создан с помощью Claude Code.

SSG генератор HTML страниц из форума помощи Discord сервера VRChatRU. Публикует только треды,
которые отмечены реакцией 🌐 от пользователя с ролью публикации. Генерация
происходит только при добавлении/удалении реакции.

## Возможности

- 🚀 Автоматическая публикация тредов из Discord форума
- 📱 Адаптивный дизайн с поддержкой мобильных устройств
- 🎨 Поддержка кастомных эмодзи, аватаров, вложений
- ✅ Навигация по ответам в тредах
- 🔍 SEO оптимизация: meta теги, OpenGraph, sitemap.xml, robots.txt
- 🔒 Безопасная загрузка внешних ресурсов (YouTube, Gumroad и др.)
- 🧩 Модульная архитектура с тестами

## Требования

- Bun v1.3+
- Discord бот с правами чтения
- Включите Privileged Intent `Server Members` для проверки роли публикации

## Установка

```bash
bun install
```

## Настройка

Создайте `.env` на основе `.env.example` и укажите:

- `BOT_TOKEN` — токен бота.
- `GUILD_ID` — ID сервера.
- `FORUM_CHANNEL_ID` — ID форума помощи.
- `PUBLISHER_ROLE_ID` — ID роли/ролей через запятую, которые могут ставить реакцию на публикацию.
- `PUBLISH_EMOJI` — emoji для публикации (по умолчанию 🌐, для кастомного укажите ID).
- `ANSWER_EMOJI` — emoji для отметки правильного ответа (по умолчанию ✅).
- `SITE_TITLE` — заголовок сайта.
- `SITE_DESCRIPTION` — описание для SEO.
- `OUTPUT_DIR` — директория вывода (по умолчанию `dist`).
- `BASE_URL` — базовый URL для canonical ссылок (опционально).
- `LOG_CHANNEL_ID` — ID канала для логов (бот будет писать только туда).

## Запуск

```bash
bun run app
```

Форс-перегенерация всех опубликованных страниц:

```bash
bun run app -- --rebuild
```

Результат:

- `www/index.html` — главная страница со списком тредов
- `www/threads/<threadId>/index.html` — страницы тредов
- `www/threads/<threadId>/meta.json` — метаданные тредов
- `www/assets/<threadId>/*` — вложения и изображения тредов
- `www/assets/avatars/*` — аватары пользователей
- `www/assets/emojis/*` — кастомные эмодзи
- `www/assets/roles/*` — иконки ролей
- `www/assets/tags/*` — иконки тегов форума
- `www/assets/style.css` — стили сайта
- `www/sitemap.xml` — карта сайта для поисковиков
- `www/robots.txt` — инструкции для поисковых ботов

## Шаблоны

Шаблоны находятся в:

- `templates/index.html`
- `templates/thread.html`
- `templates/style.css`

Доступные переменные для шаблонов:

**Общие:**
- `{{title}}` — заголовок страницы
- `{{site_title}}` — название сайта (из SITE_TITLE)
- `{{description_tag}}` — meta description (готовый тег или пусто)
- `{{canonical_tag}}` — canonical link (готовый тег или пусто)
- `{{meta_extra}}` — дополнительные SEO-теги (OpenGraph)
- `{{style_href}}` — путь к CSS файлу

**Главная страница (index.html):**
- `{{items}}` — список тредов (HTML)
- `{{updated_at}}` — дата последнего обновления

**Страница треда (thread.html):**
- `{{thread_title}}` — заголовок треда
- `{{thread_tags}}` — теги форума (HTML)
- `{{discord_url}}` — ссылка на тред в Discord
- `{{discord_button_text}}` — текст кнопки Discord
- `{{messages}}` — HTML сообщений треда (с группировкой по автору)

## Примечания

- Бот read-only: только читает сообщения и реакции, не отправляет сообщения
- Markdown конвертируется в HTML без использования JS на клиенте
- При старте бот обновляет index.html, но не перестраивает треды
- Изменения происходят только при добавлении/удалении реакции 🌐
- Поддержка загрузки внешних embed'ов (YouTube, Gumroad и др.)
- Навигация по ответам: если в треде есть сообщения с ✅, под первым постом появляются кнопки "Ответ 1", "Ответ 2" и т.д.
- Rate limiting: автоматические задержки и retry при запросах к Discord API
- Все HTML страницы статичные и могут быть захостены на любом статическом хостинге
